  For improving effectiveness specifically, the most common levers are:

  - Tighten instructions — vague steps produce vague output; replace "review the schematic" with "check for: missing
   decoupling caps, floating pins, incorrect footprints"
  - Add constraints — tell Claude what not to do (e.g., "don't suggest rerouting unless the user asks")
  - Inject live context — use !`command` to pull in current file state at invocation time so Claude sees real
  project data
  - Split into sub-skills — if the guide covers too much, break it into /pcb-schematic, /pcb-layout,
  /pcb-manufacturing so each invocation is focused

  1. You invoke /pcb-guide → skill loads, Claude reads Phase 0
